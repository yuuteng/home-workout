# home-workout

[English](README.md)

我在家每天练 20 分钟的哑铃计划。一周上肢、下肢交替,周日休息。页面列出当天的动作,跟练时语音报数、组间计时,并带打卡日历。

线上地址:<https://yuuteng.github.io/home-workout/>

![当天计划](docs/screenshot.jpg)

## 功能

- 本周七天和今天的训练卡。点任意一天看那天的计划。
- 每个动作可以展开看要点、常见错误、起始位和终点位对照,以及 B 站真人示范搜索。
- 练前约 4 分钟热身,练后约 3 到 4 分钟放松,全部站着或坐椅子做,不用铺垫子。设置里可以分别关掉。
- 跟练模式:3 秒准备,每 3 秒一次语音报数,隔几次给一条动作提示,组间休息 60 秒并提前 10 秒提醒,平板支撑按秒计时。单侧动作先数完一侧,停一下换边,再数另一侧。空格暂停,Esc 退出。
- 可选的鼓点节拍,速度和音量可调。语音、节拍、速度、音量的设置会记住。
- 跟练时屏幕保持常亮,用的是浏览器的 Screen Wake Lock 接口。
- 支持离线。添加到主屏幕后像独立 App 一样打开。
- 打卡日历显示连续天数、本月次数和累计次数,过去的日期可以补打卡或取消。记录存在浏览器 localStorage 里,可以导出或导入文本备份。

## 文件

| 路径 | 作用 |
|------|------|
| `index.html` | 整个应用:动作数据、布局、跟练引擎、打卡 |
| `sw.js` | Service Worker。预缓存页面和图片,Google Fonts 第一次用到时缓存 |
| `manifest.webmanifest`、`icons/`、`icon.svg` | 添加到主屏幕用 |
| `img/` | 动作动图(`<id>.gif`)和起止位静态图(`<id>-a.webp`、`<id>-b.webp`) |

## 修改计划

改 `index.html` 脚本开头的 `EX`(每种训练日的动作)、`WARM` 和 `COOL`(每种训练日的热身和放松)以及 `WEEK`(周几练什么)。新增或改名图片后,同步改 `sw.js` 里的 `GIFS` 和 `STILLS`,并把 `VERSION` 加一,已安装的副本才会更新。

## 本地运行

```sh
python3 -m http.server 8000
```

打开 <http://localhost:8000/> 即可。
